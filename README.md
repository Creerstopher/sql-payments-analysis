# Анализ платежей и просрочки по кредитному портфелю

SQL-проект: оценка качества кредитного портфеля — где копится просрочка, у каких клиентов и как меняется динамика.

**Стек:** PostgreSQL 16 · JOIN · CTE · оконные функции (ROW_NUMBER, LAG, NTILE, SUM OVER) · FILTER · CASE
**Данные:** полностью синтетические — 2 000 клиентов, 3 000 кредитов, 33 927 платежей. Дата среза: 31.12.2025.

## Бизнес-задача
Руководителю нужно понять: какой продукт проблемнее, как распределён долг по возрасту просрочки, на каких клиентов концентрироваться и ухудшается ли портфель.

```

   └── loans (loan_id, client_id, product, amount, rate, term_months, issued_at)

```

## Ключевые выводы
- Выдано **794,4 млн ₽**; наличные — 404,3 млн (51% портфеля).
- Просрочка по продуктам различается слабо: карты 7,3%, авто 6,4%, наличные 6,2% открытых платежей.
- **84% открытого долга** (41,2 из 49,0 млн) — просрочка старше 90 дней.
- **Концентрация:** верхний квартиль должников (203 клиента) держит **58% долга** (28,4 из 49,0 млн).
- В каждом регионе клиенты «выше среднего» должны примерно в 1,8–2 раза больше средней по региону (например, Казань: 127,6 тыс. против 66,6 тыс.).
- Доля плохих платежей (просрочка или оплата с задержкой) за 2025 год стабильна: 16,4–18,1% в месяц, устойчивого тренда нет.

## Ограничения
- Данные синтетические: неоплаченный платёж остаётся открытым навсегда (нет поздних погашений и списаний), поэтому доля 90+ завышена.
- Q9 сравнивает когорты без учёта возраста договора: старые кредиты имеют больше платежей и чаще «ловят» просрочку. Корректнее сравнивать по одинаковому сроку жизни (MOB).
